账户删除与数据权利

你可以随时在应用内删除账户并导出你的数据。本页面同时作为应用商店要求的“账户与数据删除说明”页面。

1. 在应用内删除账户

登录后进入首页的“效率云 ID → 账户安全与数据 → 删除账户”，按提示输入“删除”确认。此操作立即生效且无法恢复。网页端、Android 与 iOS 应用均使用同一入口。

2. 无法登录时

请使用注册时的邮箱或手机号向 【待填写：隐私联系邮箱】 发送删除请求，我们会先验证你对账户的控制权，再在 【待填写：处理期限，例如 15 个工作日】 内处理。

3. 删除的内容

数据处理
登录身份（邮箱 / 手机号 / 第三方登录标识）立即删除
效率云 ID、用户名、个人资料、专业版状态立即删除
任务、云端回忆立即删除
好友关系、好友申请、你发送和收到的聊天消息立即删除（对方的账户不受影响，但无法再看到与你的会话）
安全提醒设置与通知事件记录立即删除
你提交的举报记录去除与账户的关联后，为处理滥用问题保留：【待填写：保留期限】
数据库备份备份按服务商周期轮换，被删除的数据将在备份过期后彻底清除：【待填写：备份保留周期】

4. 导出你的数据

在同一位置点击“导出我的数据”，可获得包含任务、回忆和消息的 JSON 文件（Android 应用会将内容复制到剪贴板）。建议在删除账户前先导出。

5. 其他权利

依据你所在地的法律，你可能有权访问、更正、限制处理、反对处理或撤回同意，并向监管机构投诉。请通过 【待填写：隐私联系邮箱】 提出请求。

6. 退出所有设备

若怀疑账户被他人使用，可在“账户安全与数据”中点击“退出所有设备”，并立即更新密码。
